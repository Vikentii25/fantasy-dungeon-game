## How to run
```bash
python main.py
```

## Project structure
- `entities.py` — base Entity, Hero, Enemy classes
- `heroes.py` — Warrior, Mage, Archer subclasses
- `battle.py` — combat system
- `rooms.py` — room generation and trap system
- `boss.py` — Dragon boss
- `localization.py` — UA/EN localization
